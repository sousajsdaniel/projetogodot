# Início rápido — Futebol Adventure

1. Abra o Godot 4.7.2, importe `project.godot` e pressione **F5**.
2. Escolha **Iniciar** na tela inicial.
3. Ande com **A/D ou setas** e pule com **Espaço/W/seta para cima**.
4. Use **J** para dar carrinho no chão e **K/Enter** para chutar. Cada chute gasta uma bola.
5. Siga para a direita, saltando os buracos; colete bolas para munição e kits para recuperar saúde. As bandeiras salvam pontos de apoio.
6. Enfrente árbitros que lançam cartões, robôs VAR e o chefão Cartão Vermelho.
7. Após derrotar o chefão, atravesse os portões do estádio para vencer.

Você tem **3 vidas**. Cada queda ou saúde zerada consome uma vida; a última leva ao **Game Over**.

**Esc/P** ou o botão na interface pausa a partida. O menu de pausa permite continuar, reiniciar e voltar ao início. **M** ativa/desativa o áudio.

Veja `README.md` para testes e exportação.
